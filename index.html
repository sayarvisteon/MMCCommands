MMC Commands
Core ADB launcher — navigation, settings, logging, APK deployment
mmc.bat
mmc homeNavigation
Sends a Home key press via car service custom input injection (key codes 1016 & 1017).
mmc mediaNavigation
Sends a Media key press to switch to the media screen (key codes 1022 & 1023).
mmc telNavigation
Sends a Tel (Phone) button press to the IVI (key codes 1010 & 1011).
mmc vrNavigation
Sends a VR (Voice Recognition) button press to the IVI (key codes 1008 & 1009).
mmc volNavigation
Sends a Volume hard key press to the IVI (key codes 1018 & 1019).
mmc etmLaunch
Launches the ETM (Engineering Test Menu) screen — com.mmc.etm/.ETMLandingActivity.
mmc tpkpaTire Pressure
Sets Tire Pressure unit to KPA via global settings (pressure_set_value = 1).
mmc tppsiTire Pressure
Sets Tire Pressure unit to PSI via global settings (pressure_set_value = 2).
mmc tpbarTire Pressure
Sets Tire Pressure unit to Bar via global settings (pressure_set_value = 3).
mmc logenableLogging
Full VST Logger enable flow with reboot cycle.
1
adb root && adb remount
2
adb reboot → wait for device online
3
Wait 30s for system to stabilize
4
adb root && adb remount again
5
Launch VST Logger → enable HMI Log → power cycle device
mmc shortlogLogging
Quick VST Logger launch — no reboot. Runs root + remount then opens VST Logger directly. Enable HMI Log and power cycle manually.
mmc logpull <name>Logging
Pulls VST logs from device and zips newly pulled files as <name>.zip.
1
adb root && adb remount
2
Records pull timestamp
3
adb pull data/vstgloballogcontrol
4
Zips only files newer than pull start → <name>.zip
mmc pushAPK Deploy
Finds the latest app-release.apk under Downloads, matches it to a repo by keyword, renames in-place and pushes to the correct system partition.
1
Scans %USERPROFILE%\Downloads recursively for most recently modified app-release.apk
2
Prompts for app keyword — e.g. vehicle, camera, phone
3
Matches keyword → repo name (e.g. MMCVehicleApp) + partition (/system_ext/priv-app)
4
Renames app-release.apk → MMCVehicleApp.apk in-place
5
adb root && adb remount → adb push → adb shell sync × 3
6
Reboot device from POWER button

mmc 5p45Vehicle Type
Sets Vehicle Type to 5P45 — injects 0x00 at index 5, then kills com.mmc.vehicle process to apply.
mmc 5p45vVehicle Type
Sets Vehicle Type to 5P45V — injects 0x01 at index 5, then kills com.mmc.vehicle process to apply.
mmc 5f00Vehicle Type
Sets Vehicle Type to 5F00 — injects 0x02 at index 5, then kills com.mmc.vehicle process to apply.
mmc lhdDriving Hand
Sets Driving Hand to Left Hand Drive (LHD) — injects 0x00 at index 6.
⚠️Requires a power reboot on the device for changes to take effect.
mmc rhdDriving Hand
Sets Driving Hand to Right Hand Drive (RHD) — injects 0x01 at index 6.
⚠️Requires a power reboot on the device for changes to take effect.
mmc lang <name>Language
Sets Default Language — injects the corresponding byte at index 7. Run mmc lang without argument for an interactive menu.
Example: mmc lang english  ·  mmc lang arabic  ·  mmc lang japanese

Utilities
Device date, touch indicators and other quick device utilities
mmc.bat
mmc setdate <MM/DD/YYYY>Date
Sets the device date using US format (MM/DD/YYYY). Short year also accepted.

Examples: mmc setdate 06/07/2026  ·  mmc setdate 6/7/26

Runs adb root && adb remount, then picks current system time (HH:MM) and builds the adb format MMDDHHmmYYYY.00 automatically.
mmc showtouchDisplay
Enables touch indicators on the device screen.

Runs: adb shell settings put system show_touches 1
mmc gnssSystem
Enables GNSS Simulation on the device.

Runs: adb root && adb remount
Runs: adb shell setprop persist.vendor.gnss.simulation 1
Then automatically reboots the device to apply changes.

Media Capture
Capture screenshots and screen recordings from the connected IVI device
mmc ss / video
mmc ss <name>Screenshot
Takes 1 screenshot from the connected device, saved as <name>.png. (Defaults to screenshot.png if no name is provided).
mmc ss <name> <N>Screenshot
Takes N screenshots in a loop, saved sequentially with an underscore tail (<name>_1.png to <name>_N.png).

Example: mmc ss home 3 captures 3 screenshots.
mmc video <name>Video
Records the screen directly to an MP4 file using scrcpy.

Saves to <name>.mp4. Press Ctrl+C to stop recording.

RVC Test Menu
Interactive rear-view camera test suite — guidelines, VHAL injection, hardware clicks
mmc rvc
mmc rvcInteractive Menu
Opens an interactive numbered menu. Select a test case by entering its number.
# Option Description
1 Static Guidelines Injects static guideline VHAL props, kills camera process, engage/disengage RVC
2 Dynamic Guidelines Sets predictive guideline VHAL, kills camera, engages RVC with dynamic mode
3 Dynamic Guidelines + Motion Dynamic guidelines with alternating steering angle injection (−/+ sequence via 559972444)
4 RVC Engage + HW Clicks Engages RVC then toggles visibility via hardware click injection (key codes 1014 & 1015)
5 Camera Settings Launches camera settings via HW inject toggle sequence
6 SVC Test Disables RVC config, injects SVC VHAL event (557875204), transitions back
7 Launch ETM Starts com.mmc.etm/.ETMLandingActivity
9 Hysteresis Test Tests gear/speed latency logic via sequential VHAL state transitions
10 Audio Beep Engages RVC + triggers 4 HW click cycles for beep validation (run option 2 first)
11 Enable RVC Direct VHAL inject — 557891680 → 2
12 Close RVC Direct VHAL inject — 557891680 → 1
13 RVC Popup Notification Sets popup overlay VHAL (557957201) then triggers HW click
14 RVC HW Toggle Injects VHAL event 557875300 → 8 then toggles via HW clicks
15 Reset RVC Popup Clears popup VHAL array (557957201 all zeros) then HW click reset
8 Exit Returns to main mmc prompt
